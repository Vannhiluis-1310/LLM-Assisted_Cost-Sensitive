# Phase 3.1 Context: Dynamic Cost-Sensitive Decision Policies

## Locked Decisions

1. Create a new notebook for Phase 3.1:
   - `notebooks/04_dynamic_cost_policy.ipynb`
2. Keep notebook 03 unchanged as Q-bandit/LLM ablation evidence.
3. Preserve Phase 1, Phase 2, Phase 2.1, and Phase 3 as completed evidence. Do not restart the project.
4. Implement Level 3 and Level 4 first:
   - Level 3: LightGBM + global cost-sensitive threshold.
   - Level 4: LightGBM + amount-bin dynamic cost threshold.
5. Move Level 5 to Phase 3.2:
   - LightGBM + MiniLM embedding + dynamic hybrid policy.
6. Do not claim the closed-form expected-cost threshold is amount-dynamic because `TransactionAmt` cancels:

```text
Flag if p * TransactionAmt * beta > (1-p) * TransactionAmt * alpha
=> p > alpha / (alpha + beta)
```

7. Level 4 must use validation-tuned thresholds per amount bin.
8. Amount-bin boundaries and thresholds must not be derived from test labels or test metric optimization.

```text
results/baseline_scores_{RUN_MODE}.csv
```

Required columns:

```text
run_mode, sample_rows, split, TransactionID, isFraud,
TransactionAmt, model, score
```

Notebook 04 should require this file and give a clear error if it is missing.
