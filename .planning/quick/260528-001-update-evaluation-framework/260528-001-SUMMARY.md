## Key Correction Captured

The closed-form expected-cost threshold is not amount-dynamic because `TransactionAmt` cancels:

```text
p * TransactionAmt * beta > (1-p) * TransactionAmt * alpha
=> p > alpha / (alpha + beta)
```

Therefore, Level 4 uses amount-bin validation thresholds instead of claiming a closed-form dynamic threshold.
